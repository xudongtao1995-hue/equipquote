# Contributing

Thanks for helping improve EquipQuote.

1. Fork the repo and create a branch.
2. Install in editable mode: `pip install -e .`
3. Run the tests: `python -m unittest discover -s tests -v`
4. Keep changes dependency-free (standard library only) unless there is a clear reason.
5. Open a pull request describing the sales workflow your change supports.

Bug reports are most useful when they include the input JSON and the expected total.
